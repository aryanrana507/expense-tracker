# Expense Tracker

A fully static expense tracker — one self-contained `index.html`, no server, no build step, no install.

## Features

- **Add transactions** — description, amount (₹), Income or Expense, category (Food, Transport, Shopping, Bills, Entertainment, Salary, Other), date (defaults to today)
- **Live summary cards** — Total Balance, Total Income, Total Expense
- **Transaction list** — newest first, green for income, red for expense, delete button on every row
- **Filters** — All / Income / Expense + category dropdown
- **Spending by Category** — horizontal bars with totals per category
- **Clear All** — with a confirm dialog
- **Saved in your browser** — all data lives in localStorage, so entries survive reloads
- **Seed data** — 8 sample transactions (salary, groceries, metro, headphones, bills, movie, freelance, lunch) so the page is alive on first load

## Run it

Double-click `index.html`, or open it from the live link below. Works offline.
